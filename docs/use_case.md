# 设备云监 · 用例图

> 参与者：设备管理员、运维工程师、班组长。  
> 说明：Mermaid 无官方 usecase 语法，用 flowchart 模拟；`include` 表示必须包含的子用例。  
> 范围：不含权限登录、审批、多租户、移动 App 等超范围角色/用例。

## 参与者与用例关系

```mermaid
flowchart LR
  Admin([设备管理员])
  Ops([运维工程师])
  Lead([班组长])

  Admin --> UC1[管理设备台账]
  Admin --> UC2[查看实时监控]
  Ops --> UC2
  Lead --> UC2

  Ops --> UC3[处理报警]
  Ops --> UC4[处理工单]
  Lead --> UC4

  Lead --> UC5[查看统计报表]
  Admin --> UC6[管理备件]
  Ops --> UC6

  UC2 -.->|include| UC7[采集 Modbus 数据]
  UC3 -.->|include| UC7
```

## 说明

| 类型 | 内容 |
|------|------|
| 参与者（3） | 设备管理员、运维工程师、班组长 |
| 主用例（6） | 管理设备台账、查看实时监控、处理报警、处理工单、查看统计报表、管理备件 |
| include | 「查看实时监控」「处理报警」均 **include**「采集 Modbus 数据」（端口 5020 模拟从站） |

## 人工修正记录

1. AI 易增加「系统管理员 / 访客」→ **删除**（超出 v1 角色范围）。
